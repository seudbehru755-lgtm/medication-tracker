# Medication Tracker App

#### Video Demo:
https://youtu.be/liQgNAqgBzM>

#### Description:

Medication Tracker App is a web application built with Flask and SQLite that helps users manage their medications and daily reminders. Users can add medications, edit them, delete them, and mark them as taken. The application also stores medication history so users can track previously taken medications.

This project was created as a final project for CS50x.

---

# Features

- Add new medications
- Edit medication details
- Delete medications
- Mark medications as taken
- View medication history
- Store data using SQLite
- Simple and responsive user interface using Bootstrap

---

# Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Bootstrap
- CS50 SQL Library
